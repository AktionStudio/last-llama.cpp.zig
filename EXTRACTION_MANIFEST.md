## Extraction decisions

- The maintained boundary is a local JSON-lines runner with explicit CPU or CUDA build selection. It owns runtime initialization, device inspection, model load/unload, fresh request context creation, generation, cancellation checks, and shutdown. Application-provider and orchestration code is excluded.
- The generated `llama.h.zig` binding is a build product. The known working Zig 0.17 compile used a Zig 0.14.1-generated header because the lab recorded an MSVC-header translation limitation; both tools are therefore documented rather than silently substituted.
- Qwen-specific source is not used to make the generic runner depend on Qwen. The Qwen template fixture remains as evidence and an explicit optional treatment. The currently available small model is sufficient only for bounded generic CPU/CUDA reproduction.
